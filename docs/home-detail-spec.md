# 首页与活动详情页需求文档

> 适用范围：`tabs/tab-home.html` 及活动详情页相关实现  
> 版本：第一版（mock 数据，不接真实 API）

---

## 1. 首页信息架构

首页采用纵向滚动布局，从上到下依次为：

### 1.1 顶部区域
- **项目 Logo**：左侧显示 `assets/icons/app-logo.png`。
- **当前地址/定位入口**：Logo 右侧显示当前城市/区域名称（mock 数据，如「上海 · 徐汇区」），点击可展开地址选择浮层（第一版仅展示，不做真实定位）。

### 1.2 搜索区域
- **搜索框**：位于 Logo 下方，带搜索图标与占位文案（如「搜索活动、地点、主办方」）。
- 第一版支持前端 mock 关键词过滤，不接入真实搜索接口。

### 1.3 地图区域
- **地图占位容器**：占据约 40% 屏幕高度，使用深色占位背景 + 网格/点位模拟地图。
- **活动标记点**：根据 mock 活动数据在地图上渲染若干标记点，点击标记点可高亮对应活动卡片。

### 1.4 分类筛选
- 位于地图区域上方或下方，横向滚动标签栏。
- 标签项：全部、音乐、展览、放映、市集、夜游（可扩展）。
- 默认选中「全部」。

### 1.5 时间筛选
- 位于分类筛选附近，入口文案如「全部时间」。
- 点击后从底部弹出时间选择浮层，参考订酒店日期选择交互。

### 1.6 活动列表区域
- **推荐/附近活动卡片**：纵向列表或横向滑动卡片组。
- 每张卡片展示：头图、标题、时间、地点、类别标签、费用/免费标识。
- 点击卡片进入活动详情页。

## 2. 活动详情页信息架构

活动详情页为首页内嵌视图或独立片段，整体纵向滚动：

### 2.1 顶部导航
- **项目 Logo**：左上角，点击返回首页。
- **分享按钮**：右上角靠边，点击触发系统分享或复制链接（mock 行为）。

### 2.2 头图轮播
- 占顶部较大区域，最多展示 5 张活动图片。
- 支持向右/向左滑动切换，底部显示指示器。
- 图片使用占位图或 mock 图片 URL。

### 2.3 活动基本信息
- **活动标题**
- **时间**：日期 + 时段
- **地点**：详细地址
- **费用**：免费 / 具体价格
- **主办方**：名称 + 可选图标

### 2.4 活动介绍
- 正文描述区域，支持多行文本。
- 可包含段落、标签、注意事项等。

### 2.5 发起人信息
- 头像、昵称、简介/身份标签。
- 可选：关注按钮（mock 状态切换）。

### 2.6 地点真实评价
- 评价列表，每条包含：用户头像、昵称、评分、评价内容、时间。
- 使用 mock 评价数据。

### 2.7 操作按钮区
- 固定在底部或详情页末尾：
  - **收藏**：心形图标，点击切换状态。
  - **加入路线**：加入当前用户的 AI 路线（mock 提示）。
  - **发起邀约**：弹出邀约浮层或提示。
  - **地图导航**：点击跳转地图导航（mock 行为，后续接真实 API）。

## 3. 首页交互逻辑

| 交互元素 | 行为 |
|---|---|
| 定位入口 | 点击展开地址选择浮层，展示 mock 地址列表；选择后更新顶部地址文案。 |
| 搜索框 | 输入关键词后回车/点击搜索，前端按活动标题/地点/主办方过滤列表。 |
| 分类标签 | 点击切换选中态，地图标记与活动列表按类别联动过滤。 |
| 时间筛选入口 | 点击展开底部时间选择浮层，选择后更新入口文案并过滤活动列表。 |
| 活动卡片 | 点击进入活动详情页，同时记录当前活动 ID。 |
| 地图标记点 | 点击标记点，高亮对应卡片（如滚动到卡片位置或添加高亮样式）。 |
| 底部 Tab | 保持 `shell.html` 默认切换逻辑，首页为默认激活 Tab。 |

## 5. 时间筛选逻辑

### 5.1 筛选维度
- 全部时间
- 今天
- 明天
- 本周末（周六 + 周日）
- 未来 7 天
- 自定义日期范围

### 5.2 交互参考
参考订酒店日期选择：
- 点击时间筛选入口，从底部弹出日历浮层。
- 默认高亮「全部时间」。
- 选择具体日期范围后，浮层关闭，入口文案更新为所选范围。
- 活动列表按所选时间范围过滤。

### 5.3 数据过滤规则
- 每个 mock 活动数据包含 `startTime` 与 `endTime`。
- 筛选时判断活动时间与所选范围是否有交集。
- 「本周末」按当前周的周六、周日计算（mock 中可固定为示例日期）。

## 7. 腾讯地图 API 预留方案

### 7.1 当前 mock 实现
- 地图区域使用普通 HTML/CSS 占位，用圆点/图标模拟活动标记。
- 地图导航按钮点击后仅做提示，不调用真实 API。
- 活动数据中的 `coordinates` 字段仅作为预留，不参与真实定位计算。

### 7.2 预留地图容器
- 地图容器使用固定类名，如 `.home-map-container`。
- 标记点使用统一类名 `.map-marker`，并通过 `data-id` 关联活动 ID。
- 后续接入腾讯地图 API 时，只需替换容器内部实现，保持类名与交互约定。

### 7.3 后续接入替换点
1. 将 `.home-map-container` 内部替换为腾讯地图 SDK 实例。
2. 使用 mock 数据中的 `coordinates` 生成真实 `LatLng` 标记。
3. 将「跳转地图导航」按钮的点击事件替换为调用腾讯地图导航 API。
4. 地址选择浮层接入腾讯地图地点搜索/逆地址解析。
